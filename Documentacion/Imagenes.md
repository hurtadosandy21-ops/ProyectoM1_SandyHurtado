# 📈 Evolución Visual y Bitácora de Cambios

En este documento se detalla el proceso de diseño, las iteraciones de la interfaz y la evolución de los componentes de la aplicación a través de sus capturas de pantalla.

---

## 1. Estructura Inicial (Maquetación)
Esta imagen es la referencia de la estructura base de la aplicación utilizando únicamente elementos esenciales de HTML y CSS.

![Estructura Inicial](../assets/arreglo-de-botones.png)

---

##  2. Iteración y Cambio de Estilos 
Durante el proceso se evaluaron distintas alternativas visuales para mejorar los estados interactivos (como el color por defecto al seleccionar opciones).

> 📌 **Nota:** Aunque este enfoque de selección inicial se descartó, sirvió como base para rediseñar por completo el aspecto estético de los menús desplegables.

![Cambio de color de menú](../assets/cambio-de-estilo.png)

---

##  3. Estilo Definido y Nuevos Controles
En esta etapa se consolidó la línea gráfica final de la aplicación y se integraron controles esenciales para la experiencia de usuario, tales como el botón **Guardar Paleta** y el menú de configuraciones.

![Estilo definido y Botones Extras](../assets/stylo-definido.png)

---

##  4. Sistema de Bloqueo de Color (Candado)
Se diseñó e implementó la funcionalidad de bloqueo de color. Esta imagen muestra el prototipo inicial del botón de candado, el cual posteriormente fue optimizado para pantallas táctiles y dispositivos móviles.

![Bloqueo de color](../assets/boton-candado.png)

---

## 5. Optimización del Menú Desplegable
Originalmente, el menú de paletas guardadas mostraba solo 5 tarjetas por defecto y carecía de una opción de borrado. La lógica fue mejorada para permitir un control dinámico y la eliminación individual de cada paleta.

![Mejora de Menú](../assets/mejora-de-menú.png)
